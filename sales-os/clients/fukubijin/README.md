## 3. 商材ポジショニング

福美水を「低刺激スキンケア」として売らない。

営業上の再定義:

> 敏感肌の人が、施術後・美肌・エイジングなどの“攻めのケア”を諦めなくてよい一本。

さらにB2B営業では、以下の文脈で置く。

> 施術後に一時的に敏感になった顧客へ、施設側が安心して案内できる共通ケア。

入口トークは成分説明ではなく、業態の現場課題から入る。

例:

```text
施術後に肌が敏感になったお客様へ、御社では何を案内されていますか？
```

## 7. KPI設計

この案件は架電数だけを見ない。
以下のファネルで管理する。

```text
架電数
→ 接続数
→ 担当者接続数
→ サンプル送付打診数
→ サンプル送付OK数
→ 3点取得数
→ 使用感確認予定数
→ 使用感確認完了数
→ オンライン商談化数
→ SUトスアップ数
→ ヨミ化数
→ 受注数
```

3点取得:

1. 導入希望アイテム
2. 導入希望時期
3. 導入希望数量

補助KPI:

- サンプルばらまき率
- 業態別反応率
- 使用感確認の再接続率
- 商談化率
- 業態別の商談化単価見込み

## 8. 運用リスク

### リスク1: 取材動画がDriveに整理されていない

現状、取材動画はDriveフォルダ内ではなく、Membersチャット内のYouTubeリンクに依存している。
これはキャッチアップ漏れ・資料品質低下・引き継ぎ事故につながる。

対策:

- Driveの戦略フォルダに動画リンク管理mdを作る
- 文字起こし、議事録、戦略、台本の参照関係を1枚にまとめる

### リスク2: SUアサイン遅延

相談者・商談者のアサインが難航している。
ここが詰まると、台本・資料ができても開始できない。

対策:

- アサイン期限を明確化
- ロープレ予定日を仮置き
- 月末開始から逆算したデッドラインを設定

### リスク3: サンプル送付がばらまき化

サンプル送付OKだけをKPIにすると、商談化しないリードが増える。

対策:

- 送付前に3点取得
- 使用感確認日を必ず握る
- 3点が取れない場合は温度低として扱う

### リスク4: 成分説明から入り受付で止まる

ヨモギ、クマザサ、白樺などの成分説明は受付突破に向かない。

対策:

- 業態の現場課題から入る
- 施術後ケア、物販、アメニティ、店販の文脈で話す
