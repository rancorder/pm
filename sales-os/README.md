# 営業支援OS

営業支援案件のDrive原本・商談ログ・議事録・文字起こしをもとに、案件ごとの営業戦略、差分検知、定例論点、次アクションを管理するOS。

---

## ワークフロー

```text
1. Drive原本を確認
   - 戦略データ
   - 情報・データ
   - 商談ログ
   - 議事録
   - 文字起こし

2. 現状認識を更新
   - 旧認識
   - 新情報
   - 差分
   - 事実 / 仮説 / 未確認

3. 営業戦略を再設計
   - 商材価値
   - 市場の歪み
   - ターゲット優先度
   - 勝ち筋
   - 捨てるターゲット

4. 運用設計に落とす
   - 台本
   - リスト
   - KPI
   - 定例アジェンダ
   - 宿題
   - 次回確認事項

5. GitHubへ反映
   - `sales-os/clients/<client>/README.md` を正本化
   - Driveは原本、GitHubはOS正本として扱う
```
